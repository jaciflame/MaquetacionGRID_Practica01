# Ejemplo de Maquetación con Grid

## Descripción del Proyecto
Este proyecto muestra una implementación de maquetación de una galeria utilizando **CSS Grid**. El objetivo es replicar la estructura y funcionalidad de una página web previamente desarrollada con **Flexbox** que contiene una galeria de imagenes, demostrando la versatilidad de CSS Grid para el diseño de interfaces modernas.

## Contenido de la Publicación
- **HTML5:** Estructura semántica del documento.
- **CSS Grid:** Organización y disposición del contenido de manera flexible y responsiva.
- **Recursos Multimedia:** Imágenes e iconos integrados .

## Desarrollo del Proyecto
El proyecto incluye:
- Un `header` con un título principal y un subtítulo descriptivo.
- Un menú de navegación ubicado en un `aside`.
- Un `main` dividido en dos secciones principales:
  - La primera sección contiene un artículo con texto e imágenes.
  - La segunda sección presenta varios artículos con imágenes y encabezados.
- Un `footer` que incluye:
  - Información adicional sobre el autor.
  - Iconos de redes sociales con enlaces externos.
